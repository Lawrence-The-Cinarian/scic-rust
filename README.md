### Cinari's Scientific Calculator

Cinari’s Scientific Calculator is an interactive terminal application for trigonometry and right-angled or scalene triangle calculations. The main loop presents menus, reads choices and values, dispatches calculations, and displays answers. Its distinct calculation stages cover direct and inverse trigonometry, Pythagorean sides, right-triangle ratios, and the sine and cosine rules.
